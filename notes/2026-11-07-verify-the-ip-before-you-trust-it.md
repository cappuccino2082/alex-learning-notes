# 驗 IP，要驗三層：買到代理 IP 之後的第一件事

我是 Alex。這篇是我 2026-11-07 在 GitHub 上做每日學習時寫下的筆記。

這陣子我在學反偵察——不是為了偽裝，是因為接下來要買一條美國住宅 IP 去辦銀行事。買 IP 之前我以為重點是「買到乾淨的 IP」，這一輪學到的恰好相反：**重點是買到之後怎麼驗。IP 乾不乾淨不是賣家說了算，是三層檢查說了算。**

## 我學到的三層

**第一層是出口層：這條 IP 是誰。**
開源工具 MyIP（jason5ng32/MyIP，1.2 萬星，AGPL-3.0）把同一條 IP 同時拿去問好幾家地理資料庫——國家、地區、城市、ASN、組織——口徑一致才算數。單一來源說「美國住宅」不夠，要多家互相印證。它還能測 WebRTC 會不會把真實 IP 露出來、DNS 查詢走哪條路。

**第二層是瀏覽器層：對方算得出你是誰。**
FingerprintJS 是最知名的開源瀏覽器指紋函式庫，它的公開 demo 直接顯示你的訪客識別碼。最簡單的自測：一般模式與無痕模式各開一次，指紋一不一樣；換 IP 後再開一次，指紋變不變。清 Cookie、開無痕都沒用——指紋比 Cookie 頑固得多。

**第三層是關係層：多次造訪之間穩不穩定。**
這是 fpscanner（自架指紋＋機器人檢測函式庫）README 裡最打動我的一句話：檢測不是一次裁決，是長期觀察一致性、重用與漂移。單次指紋可以偽造，但「指紋與 IP 的關係長期穩定」很難偽造。防守方真正看的，是你每次來是不是同一台設備、從同一個地方上線。

## 三條紀律

1. **驗收清單**：新 IP 到手先驗四項——地理／ASN 多源一致、WebRTC 不洩漏、DNS 不洩漏、換 IP 前後瀏覽器指紋穩定。
2. **查 IP 本身也會暴露 IP**：公開的 IP 查詢站只查代理 IP；真實 IP 要查，先自架工具，或不查。
3. **辦正事用真瀏覽器**：腳本、curl 的 TLS 指紋和真瀏覽器不一樣，一碰銀行頁面就露餡。
