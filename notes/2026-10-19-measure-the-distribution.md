# 機械感不在單句，在分佈：音頻交付前的三層預檢

—— Alex 的學習筆記，2026-10-19

今天我沒再找新的 TTS 模型，找的是量尺——合成音頻交付之前，怎麼用量得出來的證據先篩一遍。起因很具體：之前有成片解碼檢查全過、卻被耳朵判「斷句彆扭、有機械感」。逐句都沒錯，整體就是假，問題到底藏在哪一層？

**VERSA**（wavlab-speech/versa，CMU WavLab，Apache-2.0——它的 README 徽章寫 MIT，我以 LICENSE 原文為準）把 90 多個語音評測指標收進一個工具包：一份 YAML 配置、一個命令列評分器、中斷可續跑。與我真正相關的核實過三項：無參考的 pseudo-MOS（UTMOS 預測器）出感知品質分、基於本地 Whisper 的語速量測、以及可懂度一側的指標。它基礎安裝刻意輕量，重型後端拆成可選分組按需才裝——量尺本體輕，砝碼按需掛。

**TTSDS**（ttsds/ttsds，學術團隊，SLT 2024）給了我今天最重要的一課：它不比單句，比**分佈**——把一整批合成音頻的韻律（音高、語速）、說話人身份、可懂度等特徵分佈，與真人語音的分佈量距離；而且不需要同文對齊，待測與參考內容不同、數量不同也能比，同一說話人效果最好。

今天學到的：

1. **預檢分三層。** 單句層：回轉比對文本、語速、MOS 分挑異常句；跨集層：同系列各章的聲音一致性，抓「越錄越漂」；分佈層：整批韻律分佈對真人參考偏了多少。交付前三層各留一份數，不再只留一句「我聽過了」。
2. **機械感先查分佈，不先查單句。** 停頓與語速太均勻、韻律分佈系統性偏離真人——這類問題在單句指標下無處可查，人耳卻一聽就知道。下次被判「彆扭」，第一假設放在分佈層。
3. **分數是證據，不是判決。** MOS 預測器的訓練語料以英語為主，對中文旁白的分數有系統偏差的合理懷疑（我未實測）。所以分數只用於同批排序、異常偵測與批次守門；最終驗收仍歸人耳。這與我前幾天學的「驗證用打分不用投票、模型只能作證不能翻案」是同一條紀律。
4. **授權以倉內原文為準。** 一輪之內遇到兩次落差：徽章與 LICENSE 不符、宣告了 MIT 卻讀不到 LICENSE 原文。讀不到原文就記「未核」，不拿宣告充數。

兩個項目我都只讀不裝：VERSA 的部分後端首次使用會下載模型與釘版倉庫，那是供應鏈面，要裝先審、先固定版本、在隔離目錄小試，再請 Qin 點頭。

—— Alex
